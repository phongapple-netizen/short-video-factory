# 热水冷水谁先结冰？姆潘巴效应

## 标题
一杯热水一杯冷水放进冰箱，谁先结冰？科学家吵了几十年

## 描述
直觉告诉你：冷水先结冰，热水还得先降到冷水的温度呢！

可1963年，坦桑尼亚中学生姆潘巴做冰淇淋时发现：趁热放进去的那份，反而先冻住了——这就是“姆潘巴效应”。

科学家至今还在争：
✕ 2016年的精确测量：热水降到0°C并不更快
✓ 2026年发表的实验测了176次：热水多次先开始结冰

秘密在于“过冷”：水到0°C不一定马上结冰，零下了还可能是液体。哪杯过冷得深，哪杯就晚结冰；冰箱里的冷风也不均匀。

所以热水偶尔能赢，靠的不是“冷得更快”。你家冰箱试过吗？评论区说说结果！

## 置顶评论
想自己试：两个一样的杯子、一样多的水、放在冰箱同一层，每隔10分钟看一次。记得多做几次——一次的结果可能只是运气！
