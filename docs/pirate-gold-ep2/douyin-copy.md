## 描述
上集问题的答案来了：四人局，B只要收买D，1枚就够！

继续倒着推👇
4人局：B 99，C 0，D 1，E 0
5人局：A 98，B 0，C 1，D 0，E 1

规律：每一轮只收买“下一轮拿0枚”的人，每人1枚，凑够一半的票就行。

彩蛋：如果规则改成必须“超过”一半，船长最多只能拿97枚。为什么？评论区说说你的推理！
