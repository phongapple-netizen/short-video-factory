# 分子的左右手·下集：硖合宪三的自我复制反应

## 标题
两百万个分子里只多1个，三轮反应后几乎全是同一种！2026诺贝尔化学奖（下）

## 描述
上集讲了分子的左右手和 ee。这一集：硖合宪三的“自我复制”反应。

① 自催化：产物自己就是催化剂——左手产物帮着造左手，右手产物帮着造右手。
② 问题来了：如果左右手按同样速度复制，51∶49 翻倍成 102∶98，比例根本没变！
③ 关键：一左一右会配对“罢工”。每次配对，左右各少一个，两边的差却一点不少——少数派越来越少，偏差就被一轮轮放大。

真实数据（2003年）：约0.00005% → 第一轮57% → 第二轮99% → 第三轮超过99.5%！
（0.00005% ≈ 两百万个分子里只多1个）

生命里的氨基酸几乎都是左手型，这种放大是一种可能的解释——最初那一点偏差从哪来，至今还在研究。评论区聊聊👇
