# 分子的左右手·上集：手性与卡根的非线性效应

## 标题
你的左手，怎么转都变不成右手——分子也一样！2026诺贝尔化学奖（上）

## 描述
左右手互为镜像，却怎么翻、怎么转都没法重合，这叫“手性”。
一个碳原子连着四个不同的基团，分子就有一对“左右手”；有两个基团相同，镜像就能重合。

左右手差别有多大？
· 香芹酮：一种闻着像留兰香，它的镜像像葛缕子
· 身体里的受体像手套，只认一只手——药物的左手版和右手版，作用可能完全不同

普通方法造出来左右各一半。偏了多少用 ee 衡量：ee =（多的 − 少的）÷ 总数，100个里70左30右，ee = 40%。

1986年卡根发现：有的反应“不走直线”——催化剂只纯一部分，产物却纯得多（正的非线性效应）。
一种解释：催化剂两两配对，一左一右的对罢工，干活的几乎都是多数派。
