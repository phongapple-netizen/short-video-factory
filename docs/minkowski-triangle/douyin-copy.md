# 闵可夫斯基不等式：一个三角形就能证明

## 标题
这个吓人的不等式，一个三角形就能证明！

## 描述
√(a²+b²) + √(c²+d²) ≥ √((a+c)²+(b+d)²)

看着复杂？换个角度：
① √(a²+b²) 就是直角边为 a、b 的斜边
② 两个直角三角形首尾相接，竖着一共 a+c，横着一共 b+d
③ 连起两端，绿边正好是 √((a+c)²+(b+d)²)
④ 两条斜边走折线，绿边走直线——三角形两边之和大于第三边！

什么时候取等号？a∶b = c∶d 时，折线被拉直。
