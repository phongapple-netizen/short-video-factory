# 分子的左右手：0.00005%变成99.5%（2026诺贝尔化学奖）

## 标题
0.00005%的偏差，三轮反应变成99.5%！今年诺贝尔化学奖讲的是分子的“左右手”

## 描述
很多分子像你的左右手：互为镜像，却不能重合。药物的左手版和右手版，作用可能完全不同——可普通方法造出来，往往左右各一半。

2026年诺贝尔化学奖授予卡根和硖合宪三：
· 卡根（1986）：产物的纯度不按催化剂纯度成比例——催化剂只纯一部分，产物可能纯得多。
· 硖合宪三：产物会催化生成和自己同一种手的分子。约0.00005%的偏差，三轮反应依次变成57%、99%、超过99.5%！

生命里的氨基酸几乎都是左手型。这种“自我放大”，为一点偏差变成全部提供了一种可能——但最初那一点偏差从哪来，至今仍在研究。
