# 三个弹簧铁球，谁先落地？

## 标题
三个一样的铁球同时剪断，谁先落地？答案取决于弹簧有没有质量

## 描述
A：剪断弹簧上面的绳子（球带着整根弹簧掉）
B：从弹簧中间剪断
C：剪断挂球的绳子

A先？B先？C先？还是D同时？先选再看👇

慢放400倍会看到：剪断后，A的球竟然在空中“悬停”了16毫秒！弹簧上端先缩下来，消息传到下端要时间。

可是把球和弹簧看成整体——剪断后只受重力，重心立刻自由下落。弹簧缩完后带着球追上来。

答案看模型：
· 理想轻弹簧（没有质量）：三球同时落地，选D。
· 真实弹簧（有质量）：严格说C最先，B晚约0.06毫秒，A晚约0.25毫秒——差距小到眼睛分不出。

想亲眼看悬停？拿彩虹圈从上端松手试试！

## 说明
- 题目装置按本片设定：A为绳—弹簧—球，剪断弹簧上方的绳；B为弹簧挂横杆、从中间剪断；C为绳—球。
- 16毫秒、0.25毫秒、0.06毫秒、1.2毫米均为 src/videos/spring-drop/model.ts 的离散弹簧模拟估算（球1 kg，弹簧50 g，k=200 N/m，原长25 cm，下落1.2 m），参数不同数值会变，不是实测结果。
- 资料：W. G. Unruh, “The Falling Slinky”, arXiv:1110.4368；NPR, “The Miracle Of The Levitating Slinky” (2012)。
