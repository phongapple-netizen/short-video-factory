# 五个海盗分金币 · 抖音文案

## 标题
五个海盗分100枚金币，第一个竟然拿98枚？！

## 描述
5个海盗，100枚金币，按资历轮流提方案，半数通过就分，不通过就下海！

第一个海盗怎么分才能保命又拿最多？答案反直觉：他独拿98枚，只给C和E各1枚！

秘诀就一个：倒着推。收买价 = 对方下一轮能拿的 + 1枚。

2人局：D 100，E 0
3人局：C 99，D 0，E 1
4人局：B 99，C 0，D 1，E 0
5人局：A 98，B 0，C 1，D 0，E 1

如果规则改成"必须超过一半"，A最多只能拿97枚！
