# 句子也有骨架？主谓宾定状补一次讲清

## 标题
改病句总丢分？3 分钟看清句子的骨架

## 正文
小孩改病句老丢分，多半不是粗心，是句子结构没吃透。

每个句子都像一棵树：主谓宾是主干，定状补是枝叶。

主干：小明（主语）吃（谓语）苹果（宾语）——谁干什么，对谁干
枝叶：红红的（定语）的、 大口地（状语）地、 跑得很快（补语）得后补

找主干有个绝招叫缩句：可爱的小明大口地吃着红红的苹果 → 小明吃苹果。枝叶去掉，意思不变，主干一目了然。

实战 3 个经典病句：
1. 听了这个故事，使我深受感动 → 成分残缺，删"使"
2. 他的学习态度有了很大的提高 → 搭配不当，态度只能"转变"
3. 克服并发现缺点 → 搭配不当，发现的应该是"问题"

口诀记牢：的定 · 地状 · 得后补
改病句三步：读通句子 → 缩出主干 → 检查枝叶
