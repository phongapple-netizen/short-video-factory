## 开场钩子（前3秒）

公式：**反常识结论或数字 + 一句挑战 + 第一帧已有画面在动**。先给结果或冲突，条件放到后面边讲边出。

| 类型 | 写法示例 |
| --- | --- |
| 反常识数字 | “100枚金币，船长独吞98枚！这个方案居然通过了？” |
| 常见错误 | “这道题，大多数人会算成80。” |
| 挑战 | “只给一条边和一个角，就能算出面积。” |
| 生活现象 | “铁比水重，铁船为什么不沉？” |

避免：第一句念题干条件、“今天我们来讲……”、首帧只有小字或空场景。
`content.json` 的 `hook.cue` 指向第一镜第一句；`check:factory` 校验它是第一句，实测配音后不超过 `hook.maxSeconds`（默认4.5秒）。
